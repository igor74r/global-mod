# Конфликты игровых файлов — журнал решений

## `common/achievement_groups.txt`
- Основа: Morgenröte.
- Добавлена отдельная группа `bpm_achievements` из полной версии Better Politics Mod.
- Дублирующие определения уровней сложности из BPM не переносились: они содержат урезанные списки достижений и конфликтуют с полными группами Morgenröte.

## `common/history/buildings/mr_buildings.txt`
- Основа: Morgenröte (458 строк).
- Версия Tech & Res короче (378 строк) и является подмножеством по непустым строкам.
- Сохранены дополнительные стартовые здания для Аргентины, Боливии, Колумбии и Молдавии из Morgenröte.

## `common/history/buildings/manzoni_printing.txt`
- Основа: Morgenröte (595 строк), поскольку она содержит более полный набор PM и уровней стартовых зданий.
- Добавлен отсутствовавший в Morgenröte блок Tech & Res для `STATE_KYOTO`, только при активной совместимости с Basileia.
- Вариант Tech & Res содержит отличающиеся значения PM и уровней для ряда государств; они не заменяли более полные блоки Morgenröte автоматически и требуют отдельной проверки баланса.

## Статус
Эти три файла — первые вручную обработанные конфликты. Синтаксическая проверка игровым парсером пока не выполнялась.
